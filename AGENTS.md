- Solo `public/` se publica. Mantener rutas relativas para GitHub Pages.
- HTML/CSS/JavaScript/SVG sin dependencias ni backend.
- No copiar datos operativos, capturas reales, identificadores internos o secretos.
- Diferenciar módulos implementados de capacidades en desarrollo. No prometer
  integraciones Meta/OLT/GIS activas o disponibilidad comercial no verificada.
- Único contacto autorizado inicialmente: grimisti95@gmail.com.
- No inventar razón social, domicilio, teléfono, dominio, clientes o testimonios.
- Aviso de privacidad provisional hasta que el titular complete los datos reales.
- No publicar, crear remotos ni hacer push sin instrucción del usuario.
- Ejecutar `npm run check` y verificar cambios visuales en escritorio/celular.
- Preservar accesibilidad, contenido sin JavaScript y ausencia de rastreadores.
