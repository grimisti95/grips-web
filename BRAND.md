# Identidad de GRIPS

## Concepto

Una **G abierta que conecta con un nodo**. El trazo continuo representa el hilo
del trabajo del ISP y su apertura hacia integraciones. El nodo claro superior
actúa como punto de orientación. Es una construcción vectorial nueva para esta
entrega; no se reutilizaron marcas o logotipos de otras empresas.

El nombre público es **GRIPS**. No se inventó una expansión del acrónimo.

## Entregables

- `public/assets/brand/grips-logo.svg`: firma horizontal, fondo claro.
- `public/assets/brand/grips-logo-light.svg`: firma horizontal, fondo oscuro.
- `public/assets/brand/grips-symbol.svg`: símbolo y favicon.

Los SVG se pueden abrir en el navegador y editar con herramientas vectoriales.
El símbolo usa trazos geométricos; la firma usa texto Arial/Helvetica con
alternativas del sistema. Para imprenta se puede convertir ese texto a curvas
en el editor vectorial elegido, conservando proporciones y espaciado.

## Paleta

| Uso | Color |
| --- | --- |
| Verde profundo / texto | `#17241F` |
| Lima / acento principal | `#C4EE91` |
| Fondo marfil | `#F7F7F2` |
| Texto secundario | `#647168` |
| Acento lavanda | `#EDEAFA` |

La landing utiliza fuentes del sistema, sin descargas de fuentes externas.
Deja alrededor del logotipo al menos una cuarta parte de la altura del símbolo.
Usa la firma a partir de 110px de ancho y el símbolo a partir de 24px. Evita
estirar el logo, cambiar el orden de sus elementos o colocar la versión oscura
en fondos sin contraste.

La entrega no incluye una búsqueda de disponibilidad registral de la marca ni
afirma que el nombre esté registrado. No se usa un símbolo de marca registrada.
